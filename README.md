# VisDrone2019-DET dataset audit: notebook

Notebook `visdrone_audit.ipynb` for the dataset audit homework. The written results are in the repo `visdrone-audit-report`.

The dataset is not included. The notebook expects the three folders (VisDrone2019-DET-train, -val, -test-dev) in `~/Documents/Machine Vision Course`. Figures and evidence lists are written to `~/Documents/visdrone-audit/reports`.

Libraries: pandas, numpy, opencv-python, pillow, matplotlib, imagehash, albumentations, scikit-learn, tqdm.
